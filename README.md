## ✨ Características Principales

- 🎮 **Gestión y Sincronización de Modpacks:**
  - Descarga, instala y actualiza modpacks oficiales del servidor en un solo clic.
  - Soporte integral para **Fabric**, **Forge**, **NeoForge** y **Vanilla**.
  - Comprobación inteligente de archivos con actualización delta para ahorrar tiempo y ancho de banda.

- 🧍‍♂️ **Visor 3D Interactivo de Skins y Capas:**
  - Modelo 3D interactivo en tiempo real con animación de caminata y rotación fluida.
  - Soporte de **doble capa** (capa base + overlay de cabello, flequillo y accesorios).
  - Catálogo de capas oficiales y conmemorativas de Minecraft.
  - Compatibilidad tanto para cuentas Offline como para sincronización de cuentas oficiales Premium.

- 🌐 **Arquitectura de Skins P2P / LocalSkin:**
  - Distribución descentralizada de skins entre clientes sin cuotas ni saturación de servicios externos.

- ☕ **Gestión Inteligente de Java:**
  - Detección automática de runtimes de Java instalados en el sistema (Java 8, 17, 21).
  - Descarga e instalación automática del Java adecuado según los requerimientos de la versión de Minecraft.

- 🔄 **Actualizador Automático Integrado:**
  - Notificación de nuevas versiones directamente dentro del launcher con changelog y enlace directo de actualización.

## 🚀 Guía de Instalación

1. Descarga el instalador **MiLauncher-Setup.exe** desde la sección de [Releases](https://github.com/Carlitos999yt/MiLauncher/releases/latest).
2. Ejecuta el archivo descargado. Si Windows Defender SmartScreen muestra un aviso, haz clic en **Más información** -> **Ejecutar de todas formas**.
3. Sigue los sencillos pasos del asistente de instalación. Puedes elegir crear un acceso directo en el Escritorio.
4. Al finalizar, marca la casilla **Ejecutar MiLauncher** y comienza a jugar.
